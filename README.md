HTML & CSS Basics Project

This repository contains three beginner-level web development tasks created using HTML and CSS. The project demonstrates basic webpage structure, form creation, and navigation menu styling.

📌 Projects Included

1. Basic Webpage

A simple webpage containing:

- Heading
- Paragraph
- Image
- CSS styling

2. Basic Form

A simple form containing:

- Input field
- Submit button
- CSS styling

3. Navigation Menu

A simple navigation menu containing:

- Home
- About
- Contact

The navigation links are styled using CSS and displayed as a clean menu.

🛠️ Technologies Used

- HTML5
- CSS3

🎯 Learning Objectives

Through this project, I practiced:

- Creating the basic structure of an HTML webpage
- Using headings, paragraphs, and images
- Creating HTML forms
- Adding input fields and buttons
- Creating navigation menus using HTML
- Styling webpages using CSS
- Linking external CSS files with HTML
- Organizing files for a basic web project

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code or any other code editor.
3. Open any ".html" file in a web browser.
4. Explore the webpage, form, and navigation menu.
